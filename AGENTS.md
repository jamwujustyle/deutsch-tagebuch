# Structure

- Keep material in `sources/<source>/<course>/lektion-NN.md`; separate each source and course.
- Record the supplied shared date as `YYYY-MM-DD` in Asia/Almaty; do not treat it as a learning date.
- Keep uncertain lesson assignments in `unassigned/<date>-<topic>.md` within that course; never invent a lesson number or missing material.
- Preserve supplied prompts and their order; update existing notes without duplicating re-sent lists.
- Commit each lesson separately with its number and shared date in the subject; keep unrelated material separate.
- For historical imports, use the supplied day as the author date (00:00 local when time is unknown), retain the actual committer date, and preserve existing history.
